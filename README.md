# Evaluacion2 
 
## Descripción 
Script Python para calcular rutas con la API GraphHopper Directions. 
 
## Funcionalidades 
- Interacción e instrucciones en español. 
- Distancia y duración con máximo dos decimales. 
- Salida mediante «s» o «salir». 
 
## Requisitos 
- Python 3 
- Paquete requests 
- API Key de GraphHopper 
 
## Ejecución 
1. Instalar dependencias: pip install requests 
2. Configurar la API Key de forma segura. 
3. Ejecutar: python3 Ruta_viaje_es.py
